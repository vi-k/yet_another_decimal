# Русский README

## Что просил владелец

Перевести `README.md` на русский, положить перевод в корень, убрать его из
публикации на pub.dev и держать актуальным всегда.

## Что сделано

- `README.ru.md` в корне — полный перевод всех 961 строки английского
  оригинала. Структура один в один: 36 заголовков там, 36 здесь, 64 блока кода
  там, 64 здесь.
- `.pubignore` пополнен строкой `README.ru.md`. Проверено:
  `dart pub publish --dry-run` показывает в архиве только `README.md` и
  `example/README.md`, 0 предупреждений.
- Правило «перевод обязан быть актуальным» записано в двух местах: коротко в
  `AGENTS.md` (раздел «Язык» и карта документов) и подробно в
  `docs/conventions.md` (новый раздел «README и его перевод»). Плюс пункт 10
  в решениях владельца в `docs/handoff.md`.

## Решения по ходу перевода

- **Английский — исходник, русский — перевод.** Обратного направления нет:
  правка сначала ложится в `README.md`, потом переносится. Иначе через десять
  правок это будут два разных документа.
- **Таблицы замеров переносятся один в один.** Числа, метки `★`/`▼`, шапки
  колонок — как есть. Перевод не самостоятельный замер, и пересчитывать в нём
  нечего. Перенос сделан скриптом из `README.md`, а не руками, чтобы совпадение
  было побайтовым.
- **Комментарии внутри примеров переведены, сам код — нет.** Вывод в
  комментариях (`// 59.97`, `// 1 / 8 = 0`) оставлен как есть: это часть
  примера, а не проза.
- **Имена из API не переводятся** — `base`, `scale`, `normalized()`, имена
  бенчмарков. Цитата из описания `big_decimal` («a bugless implementation…»)
  оставлена по-английски: это цитата.
- **Якоря оглавления пересчитаны** по переведённым заголовкам, все десять
  ссылок проверены на соответствие заголовкам. Заголовок
  `### [decimal](…) vs [yet_another_decimal](…)` содержит ссылки, и якорь у
  него тот же длинный и уродливый, что в английском файле, — перенесён как
  есть.
- **Ссылка на английский оригинал** стоит в шапке перевода. Обратной ссылки
  в `README.md` нет намеренно: это опубликованный артефакт, и лишней записи
  о файле, которого в пакете нет, там быть не должно.
- **Терминология зафиксирована списком** в `docs/conventions.md`: масштаб,
  база, каноническая форма, упаковка, стенд, проход, сток, хвостовые нули,
  переполнение, конечная десятичная запись. Список нужен затем, чтобы
  следующая сессия переносила правку теми же словами, а не своими.
