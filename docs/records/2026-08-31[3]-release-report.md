# Публикация 1.2.0

## Связка

Прошла целиком и подряд, как требует `AGENTS.md`, по прямой просьбе владельца,
состоявшей только из неё:

```bash
git commit --allow-empty -m 'Release 1.2.0'   # 65f301e
git tag v1.2.0
git push origin main
git push origin v1.2.0
dart pub publish --force
```

**Коммит пустой намеренно.** Версия в `pubspec.yaml` и запись в `CHANGELOG.md`
были готовы и закоммичены раньше, менять к моменту публикации было нечего, но
связка требует своего коммита — и тегу нужен якорь, который называет себя
релизом, а не правкой документации. Прошлые релизы тегировались на
содержательный коммит (`v1.1.2` → «Change version»), потому что там правка
версии как раз и приходилась на момент публикации.

Ответ сервера: `Successfully uploaded https://pub.dev/packages/denary version
1.2.0`. Страница обновляется до десяти минут.
