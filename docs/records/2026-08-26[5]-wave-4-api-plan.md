# Волна 4. Публичный API

Всё аддитивно: ни один существующий член не меняет смысла. Ломающее — в 2.0.

Пакет опубликован, поэтому каждый новый символ придётся поддерживать. Отсюда
правило волны: **добавляется только то, что названо в спеке**, и каждый член
получает dartdoc и тесты в обоих семействах.

## Порядок

### 1. Недостающие члены

| Член | Семантика |
|:--|:--|
| `precision` | как у `decimal`: число знаков в неупакованном значении, у нуля — единица. Сверяется с конкурентом тестом |
| `isPositive` | строго больше нуля; ноль не положителен и не отрицателен |
| `inverse` | точная дробь `1/x` (`Fraction` и `ShortFraction`), а не `Decimal`: обратное к трём не представимо |
| `toJson` / `fromJson` | строка, та же, что `toString`/`parse` — как у `decimal` |
| `Decimal.toInt()`, `ShortDecimal.toBigInt()` | сейчас у каждого семейства своё |
| `pow` с отрицательным показателем | `1 / x^-n`; бросает то же, что деление, когда результат не представим |
| `Fraction`: `compareTo`, `abs`, `inverse`, `toDouble` | публичный тип без сравнения и модуля |
| `ShortFraction.toShortDecimal()` | есть у `Fraction`, нет у пары |

### 2. `toStringAsExponential` и `toStringAsPrecision`

У `Decimal` они бросают `UnimplementedError`, у `ShortDecimal` их нет вовсе.
Семантика берётся у `double` и сверяется с `decimal` — у конкурента оба
реализованы, и расхождение будет означать ошибку, а не вкус.

### 3. Тотальное деление

```dart
T? divideOrNull(T other);
T divide(T other, {int? scaleOnInfinitePrecision});
bool isDivisibleBy(T other);
```

Обоснование в спеке: `throw` + `catch` стоит 803 нс, возврат `null` — 0.4 нс, и
заглавный путь пакета оказывается его самым медленным. Убирать `throw` из
`operator /` — это 2.0; здесь только добавляем тотальные формы.

### 4. Мост между семействами

`lib/src/bridge.dart`: `ShortDecimal.toDecimal()` — всегда безопасно,
`Decimal.toShortDecimalOrNull()` — `null`, когда не помещается. Межсемейных
операций не будет, это решение владельца.

### 5. Интерфейс `FixedPoint`

`lib/src/fixed_point.dart`, **не экспортируется** из
`lib/yet_another_decimal.dart`. Самоограниченный дженерик
`FixedPoint<T extends FixedPoint<T>> implements Comparable<T>`, оба семейства
его реализуют.

Смысл — дисциплина компилятора: забыли член во втором семействе — ошибка
сборки, а не находка ревьюера через год. Цена измерена и равна нулю.

Пишется **последним**: интерфейс фиксирует набор членов, а набор становится
известен после пунктов 1–4.

### 6. Тест симметрии

Интерфейс не покрывает статику — конструкторы, `parse`, `tryParse`, константы.
На них отдельный тест, сверяющий наборы публичных членов двух семейств, с
**явным списком осознанных расхождений**: `shiftLeft` у `ShortDecimal`,
`optimize()` у `Decimal`, `toBigInt` против `toInt`, `fromBigInt`.

## Готово, когда

- тест симметрии зелёный, список расхождений явный;
- у каждого нового члена есть dartdoc по-английски и тесты в обоих семействах;
- покрытие остаётся 100 %;
- `dart pub publish --dry-run` без предупреждений;
- `dart analyze`, `dart format`, `dart test` чисты.
